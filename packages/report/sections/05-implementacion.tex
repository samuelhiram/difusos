\section{Implementación}

\subsection{Arquitectura del monorepo}

El proyecto se organiza como monorepo con pnpm y Turborepo. La aplicación web usa Next.js App Router con TypeScript y Tailwind CSS. La interfaz usa componentes estilo shadcn/ui, React Flow para el grafo, Recharts para gráficas, Motion for React para animación y KaTeX para fórmulas en vivo \citep{nextjs2026app,turborepo2026next,shadcn2026monorepo,reactflow2026overview,recharts2026docs,motion2026react,katex2026browser}.

\begin{lstlisting}
apps/web
packages/fuzzy-core
packages/report
\end{lstlisting}

\subsection{Motor difuso}

El paquete \texttt{fuzzy-core} contiene TypeScript puro. Sus módulos principales son:

\begin{itemize}
  \item \texttt{membership.ts}: funciones triangular y trapezoidal.
  \item \texttt{rules.ts}: reglas lingüísticas.
  \item \texttt{mamdani.ts}: inferencia min-max.
  \item \texttt{centroid.ts}: defuzzificación.
  \item \texttt{academic-risk-system.ts}: definición del sistema.
\end{itemize}

\subsection{Interfaz}

La interfaz muestra entradas numéricas, funciones de pertenencia, grados calculados, reglas activadas, valor $\alpha$ por regla, área recortada, salida agregada, centroide, resultado crisp y etiqueta lingüística final. El grafo visual sigue este orden:

\[
\begin{aligned}
\text{Entradas} &\rightarrow \text{Fuzzificación} \rightarrow \text{Grados} \rightarrow \text{Reglas}\\
&\rightarrow \text{Recorte} \rightarrow \text{Agregación} \rightarrow \text{Centroide} \rightarrow \text{Resultado}
\end{aligned}
\]
