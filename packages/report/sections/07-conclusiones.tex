\section{Conclusiones}

El sistema difuso Mamdani propuesto modela el riesgo académico como una transición gradual y no como una decisión binaria. La combinación de variables lingüísticas, reglas IF-THEN, agregación por máximo y centroide permite obtener un resultado numérico explicable.

La solución es adecuada para demostración académica porque expone funciones de pertenencia, reglas activadas, grados $\alpha$, recortes, agregación y defuzzificación. No depende de datos históricos ni entrenamiento, por lo que se mantiene dentro de la lógica difusa clásica.

  \item Reglas IF-THEN visibles.

  \item Agregación con máximo.
  \item Defuzzificación por centroide.
